# Pradeep Birare — Portfolio Website

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension.

## Publish it free with Netlify (quickest)
1. Extract `pradeep_portfolio.zip` on your computer.
2. Go to https://app.netlify.com/drop and sign in / create an account.
3. Drag the **pradeep_portfolio** folder (the folder containing `index.html`, `style.css`, and `script.js`) into the drop area. If folder upload is not accepted, drag the extracted files together or connect a Git repository using the Netlify dashboard.
4. Netlify will publish the website and provide a public URL such as `https://your-site-name.netlify.app`.
5. In Site configuration, change the site name if the name is available. Test the URL on mobile and desktop.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `pradeepbirare-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment and open the published URL shown in the Pages section. It will usually look like `https://USERNAME.github.io/REPOSITORY/`.

## Before publishing
- Confirm your phone number, email, education, CGPA, experience dates, project descriptions, and certifications.
- Your phone number and email are public on the portfolio. Remove them if you prefer not to display them.
- Add actual GitHub repository links to each project when available. The current project cards are descriptive previews, not links to project source code.
- This package does not itself publish the site. You must complete one of the hosting workflows above to receive a live public URL.
- Google Fonts requires an internet connection; the site otherwise uses local HTML/CSS/JS files.
